# 字幕搜索扩展（2026-10-25）

| 来源 | 应用内搜索 | 下载/选择 |
| --- | --- | --- |
| ASSRT | 保留搜索与分页 | 原有文件列表与地址解析 |
| SubHD | 新增搜索与分页 | 详情网页或二维码，完成站点验证后下载 |
| Subtitles.website | 纳入聚合搜索 | 直接选择字幕地址 |
| R3 字幕网 | 网站搜索入口，片名转繁体 | 浏览器或扫码操作 |

默认全部来源并行搜索前三站。单站失败保留其他站结果并提示不可用来源，单独选站不会跳到其他站。SubHD/R3 页面不会作为字幕送给播放器，不绕过站点验证；没有浏览器时保留二维码。

查询依次尝试原词、清理版本标记后的片名、简体和繁体片名，去重且最多四次。仅无结果时重试，分页沿用命中片名，保留续集数字。语言偏好支持中文、粤语、繁体、双语及原相关性排序；片名相关性优先，不丢弃其他语言。调整偏好不重新联网，恢复原排序使用原始结果。结果显示来源、语言和网站下载提示。

## 超时修复

真实设备搜索发现 OkHttp 超时也会将 Call 标为 canceled，旧的 `!call.isCanceled()` 吞掉超时回调，聚合搜索无法结束。现使用独立完成标记：显式用户取消静默，超时正常失败；每个请求另有 8 秒期限，覆盖上游永不回调。关闭响应资源，迟到或重复回调不重复发布。

超时测试在旧实现失败，修复后通过。其他测试覆盖无回调请求、显式取消、部分失败、聚合取消、分页失败保留上一页、切换来源后的旧回调、简繁重试、粤语排序与外链禁止解析。
