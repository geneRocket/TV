# 字幕搜索与 UI 检查（2026-10-27）

## 发现和修复

- `SubtitleSearchController`：第 2 页网络失败会把来源标记为已耗尽，重试被挡住。保留已接受页，记录实际失败操作，重试原页；加载中重复重试无效。原实现的定向回归测试失败，修复后通过（`/tmp/tv-subtitle-review-red.log`）。
- 原文件列表没有返回搜索结果的路径。现在返回键和返回结果按钮恢复原页、排序和列表位置，不再发请求；取消旧文件列表和下载，忽略迟到回调。切查询或来源清除旧父页面。
- 输入框支持硬件 Enter 和键盘搜索，单次输入不重复搜索；有关键词的空结果显示“无结果”。仅在明确搜索、翻页或返回后转移焦点，使用列表差异更新保留焦点。
- TV 的主题主色让搜索按钮发黑、网站操作文字在深色背景不可读；手机浅色主题原正文使用白字。字幕搜索局部主题改为蓝底白字，正文跟随主题，网站操作使用强调色。
- 原固定 600dp 窗口超出小屏，底部面板的内容高度还可能压缩列表。按显示尺寸限制窗口并设置面板高度；来源等按钮均分空间，缩小内边距，横竖屏变化重新计算。
- 网站二维码与文字置于滚动区域，按屏幕高度缩小二维码并前置，避免短屏二维码被裁切；按钮固定在弹窗底部。打开来源、偏好或网站菜单时取消旧下载，避免迟到结果覆盖用户操作。
