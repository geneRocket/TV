# 界面状态检查与修复（2026-10-20）

本轮包含上一轮尚未提交的暂停进度框与加载圈修复。重点检查 TV/手机的点播、直播、投屏交互状态，并检查首页、分类、设置 Fragment 的观察者生命周期、文件选择回调以及现有界面回归测试。没有进行所有页面的逐像素、全部设备与分辨率验证。

## 修复

| 路径模块 | 触发条件与旧行为 | 根因与修复 |
|---|---|---|
| TV 点播 `TvVodPlaybackStateBinder` / `VideoActivity` | 缓冲时暂停，或中央进度框显示期间持续缓冲，两种提示叠加 | 暂停只取消任务，没有隐藏加载圈；缓冲未清除中央提示。暂停隐藏加载圈并取消延迟任务，缓冲显示前清除中央提示 |
| TV 投屏、直播 | 中央进度提示显示期间开始缓冲；投屏缓冲期间暂停 | 补齐加载圈与中央提示的互斥切换 |
| 手机点播、直播 | 缓冲期间暂停仍转圈；拖动提示显示期间收到缓冲事件 | PAUSED 隐藏加载圈，显示加载圈前隐藏拖动提示；手机直播同步暂停按钮状态 |
| 手机 `CustomKeyDownLive` / `CustomKeyDownVod` | 系统取消触摸、页面退出或锁定时，拖动、亮度、音量、临时倍速没有完整收尾 | 取消手势通过 release 结束，不提交 seek；释放并清除全部活动标志，重复释放不重复回调。直播页 onPause 调用 release |
| 手机直播回看、TV 投屏 | 已暂停时拖动进度，松开后自动播放 | seek 后无条件调用 onPlay。移除强制播放，保留引擎既有播放意图；投屏退出拖动提示并保留暂停提示 |
| 手机直播回看 | 拖动期间切换成无有效时间轴的流，结束手势后提示残留 | 旧代码先检查 isVod 再隐藏提示。改为先隐藏提示，无有效时间轴时同时重置拖动状态 |
| 手机直播临时倍速 | 原速度不是 1 倍，长按倍速结束后被重置为 1 倍 | 记录长按前速度并恢复；未实际开始倍速时不修改速度 |
| 手机点播首页、设置文件选择 | 文件提供器返回 RESULT_OK，但 Intent 为 null 或没有 URI，可能崩溃 | 检查 Intent、URI、Fragment 附着状态和解析后的路径；无有效结果不继续播放、传输或导入配置 |
